CS 素材助手

下載安裝包，快速查找文字 Template、圖片及 PDF 教材。

下載插件 ZIP 下載插件 ZIP

下載後請先解壓縮；ZIP 並非可直接安裝的 Chrome 商店套件。

主要用途

  • 使用獨立小視窗查找及使用 CS 素材。
  • 文字 Template 儲存在自己的 Chrome，可匯出／匯入備份。
  • 圖片及 PDF 由管理員集中維護。

實際功能以下載的插件版本為準。

首次安裝

  1. 下載 ZIP，解壓縮到一個固定資料夾。
  2. 在 Chrome 網址列輸入 chrome://extensions。
  3. 開啟右上角「開發人員模式」。
  4. 按「載入未封裝項目」，選擇直接包含 manifest.json 的資料夾。
  5. 在 Chrome 拼圖選單釘選「CS 素材助手」，點擊圖示開啟。

現有同事更新插件

  1. 先匯出文字 Template 備份。
  2. 關閉插件小視窗，再下載及解壓新版 ZIP。
  3. 將新版插件檔案覆蓋到原本安裝的固定資料夾，保留原有資料夾位置。
  4. 到 chrome://extensions，按該插件的「重新載入」。
  5. 重新開啟插件，按「重新整理教材」。
更新提醒：一般更新不需要移除插件。 移除插件可能清除本機資料。只有教材更新時，通常只需重新整理教材，不必下載新安裝包。 如公司政策禁止開發人員模式或手動安裝，請先向 IT 確認。

圖片及 PDF 使用

PDF 建議下載後，從檔案總管拖曳到 WhatsApp Web／Woztell。 圖片複製及其他操作以插件版本和聊天平台支援情況為準；插件不會自動發送訊息。

本頁及下載檔案為公開資源，持有網址的人均可存取，不設登入限制。 請勿在安裝包或教材中放入家長／學生個人資料、密碼、API 金鑰或內部機密。 本頁不需要讀取聊天內容，也不會收集個人文字 Template。
